The trick-or-treat map

🎃 Jubail Trick-or-Treat

Sign your home up, drop a pin, and manage everything yourselves on the night — out-of-treats toggle, gate directions, allergy-friendly teal pumpkins. Built for Halloween 2026, with 122 homes across five villages.

Every tool here follows the same rules: no names, no phone numbers — only unit numbers and pin locations, and seasonal data is deleted after each event.

The story

From one WhatsApp message to a live map, the same day.

In October 2026, a neighbor asked our island's WhatsApp group if anyone could organize trick-or-treating across the community. The map went live the same day — home sign-ups, private self-serve controls for every family, an organizer panel — built with AI as the workbench.

Features the community asked for shipped within hours of the ask — the gate directions, the allergy-friendly teal pumpkins, the printable list. The approach: find the real problem, ship the smallest thing that solves it, iterate in public, and hand the keys to the people who will run it.

How these get built

Ideas come from neighbors.

Almost every feature on the map started as a message in a community group — the gate colors, the allergy-friendly option, the Arabic requests. If you have an idea for something our community could use, post it in the Residents Hub or send it my way. More community tools are in the works for the winter season.
