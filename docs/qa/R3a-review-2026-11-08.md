  (`page: false` for Courts / Pets / The Community today; **R4c flips `bookings` to `page: true`**, one line).
  `admin` needs any admin role: a non-empty `admin_scopes` (incl. a `bookings`-only admin), `admin_events`, or
  `is_owner`. Strict reader `jcShellSaved` (prefs `shell` v1; anything odd → default bar), `jcShell` (live re-filter
  each render, `known` auto-append, ≤ 4 + My Home). Default with no prefs = today's bar (Commons · live modules · My Home).

- `assets/landing.js`: start page: first page of the visit, plain hub URL only (`?community=` tolerated), before the
  hub paints, `location.replace`; unavailable start → hub; member without a home → `home/` as before.
- `home/home.js` + `home.css`: Account tab → "Bottom bar and start page" (Show switch `role=switch`, Move up / down,
  My Home fixed row, start-page radios, Save) + "Save Commons as an app" help (iPhone, Android, sign in again, reset
  in Safari). Save = fresh `jc_me_get` → merge **only** `shell` → `jc_prefs_set`. Unsaved choices survive tab switch +
  language toggle; the section carries `data-no-autoreload` while unsaved (update banner, no reload).

- `assets/strings.js`: EN + AR (AR **DRAFT, pending review**). `assets/icons.js`: new dots-only `tools` glyph for

## security-reviewer (light pass, read-only) — no material findings

- Reader: no prototype pollution (registry lookup is a loop compare; module lookup uses `hasOwnProperty`); no prefs
  string reaches the DOM, an href or `location.replace` (only registry `path` / labels); type checks + 12-entry cap.
- Admin gating: `admin_scopes` / `admin_events` / `is_owner` come from the server (`jc_me_get`), not prefs; display
  only; every admin RPC still gates server-side.
- Start-page redirect: target is always a fixed relative registry path; only on the plain hub URL; not an open redirect.
  `JC_FIRST_PAGE` is a UX flag that fails safe (no storage → no redirect).
- Info: an own `"__proto__"` key in stored prefs would re-prototype the local merge object (self-only, harmless).
  **Fixed anyway:** the merge skips `__proto__`.
