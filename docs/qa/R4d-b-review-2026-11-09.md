# R4d (b): My Bookings → Past (screen): code review (2026-11-09)

- **PR:** `feat/r4d-past-ui`, on top of R4d (a) (#84; `jc_my_bookings_past()` is applied to live).
- **Plan:** `docs/plans/R4d-booking-history.md`.
- **Tier:** screen logic → code-reviewer. The server side had its database + security reviews in R4d (a).

## What changed

- **The My Bookings tab:**
  - A visible **Upcoming** heading.
  - A read-only **Past** section below it: court, day and time (community time), and **Done**, or **Cancelled** with
    the organizers' reason. Newest first, "Bookings are kept for 90 days." EN + AR.
- **Loading:**
  - Read in its own request each time the tab opens; a failure shows Try Again there only, and Upcoming stays.
  - Never asked without a home.
  - `MODULE_OFF` goes to the off page.
- **Upcoming rows** get the shared `slot slot-mine` look again (blue, as "Your booking" on a court's day). It was lost
  when the slot colours moved into `assets/slots.css`.
- **Help:** "My Bookings" now mentions Past.
