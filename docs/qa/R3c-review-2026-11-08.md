## code-reviewer: APPROVE, no High/Med

| # | Sev | Finding | Disposition |
|---|---|---|---|
| 1 | Low | `jcTabsWire` keydown swallowed modified arrows (Alt/Cmd+← = browser Back) | **Fixed**: modifiers return early; test presses Shift+← and asserts the tab didn't change |
| 2 | Low | `jcFocusKeep`'s 20 s "last focus" memory could pull focus after a tap on blank space followed by an async redraw | **Fixed**: a `pointerdown` outside any control clears the memory |
| 3 | Info | tab `.focus()` without `preventScroll` may scroll the row into view | **Accepted**: the row is where the user just acted; matches the old admin behaviour. No jump seen in screenshots |
| 4 | Info | no test for the banner draft surviving a tab switch | **Fixed**: added to the Organizer Tools tabs test (keyboard switch away and back keeps "Road closed") |

Confirmed fine by the reviewer: clicking the selected tab still redraws; `?tab=` writes unchanged; drafts captured
before `show()`; `ADM_TABS` hoisting and single-tab case (no tablist, no panel wrapper); background refreshes
(event-day 2-min, map) don't go through `show()` so the rescue never runs on them; the rescue never focuses a text
field (no iOS keyboard) and uses `preventScroll`; all new HTML escaped; tests fail on the old markup.
