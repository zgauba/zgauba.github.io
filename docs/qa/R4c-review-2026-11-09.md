PR: `feat/r4c-residents-book`. Plan: `docs/plans/R4c-residents-book.md` (Zee "go", 2026-11-09: privacy wording,
map, My bookings on top, Private switch until the slot starts).

**Tier:** screen logic + **security** (the first resident screen that shows other homes) →
**security-reviewer + code-reviewer**. Both reviewed `6c6b222`; fixes are in the next commit.

**Client only:** no migration, no RPC change.

## Security review: no High or Medium

| # | Sev | Finding | Disposition |
|---|---|---|---|
| L1 | L | The client "fails open" when `jc_config_get` fails (it asks the booking RPCs, which answer `MODULE_OFF`) | **Accepted.** The server is the gate (`jc_module_on` in every RPC), and `MODULE_OFF` routes to the off page. Failing closed on a config hiccup would hide Courts from everyone where they are on |
| L2 | L | The disclosure said "home number", but neighbors see village + number (e.g. "Villa 40 · Seef Al Jubail") | **Fixed.** `join_privacy`: "show your home (village and number)" (EN + AR). *Changes Zee's approved wording for accuracy; flagged to Zee* |
| L3 | L | Members who joined before never see the amended join text; Private is unticked on every booking | **Accepted.** Zee decision Q7 (visible by default). Jubail has no accounts yet. The booking sheet itself states it every time |
| L4 | L | Organizer reasons are resident-facing free text (a name could be typed) | **Fixed (copy).** The block-reason help and cancel-reason label now say "no names" (EN + AR) |
| L5 | L | "No third parties" sits next to map tiles from OSM / Esri (IP + tile coordinates) | **Pre-existing** (events pages). Backlog: soften the wording or self-host tiles |
| L6 | L | An apartment with a null building renders "{b}" | **Accepted.** Apartments carry a building (schema); cosmetic |
| L7 | L | A booking that lands after leaving the court shows no message | **Accepted.** It appears in My bookings (now guaranteed, see code M1) |
| Note | — | Confirm `jc_booking_cancel` checks ownership | **Verified live 2026-11-09.** `where id = p_booking and home_id = v_home …` |

Confirmed sound:
- No leak beyond what the server sends: the home is rendered only for state `booked` with an object `home`; unknown
  states fall to "Over".
- `p_private` is always a boolean.
- XSS-clean, including the Leaflet tooltip.
- `?court=` is validated.
- The CSP is right.
- With the flag off, no booking RPC is called.

## Found while testing

- **Started slots stayed bookable.** A free slot that had started (not ended) still offered Book; the server refuses
  a past start. It now shows Over (the mutation check found the gap).
- **The map's role.** `role="img"` on the map nested its zoom buttons (axe `nested-interactive`), so it is now
  `role="region"`.
- **The shell test** asserted Courts never shows because it had no page. It now shows where the flag is on, and
  Pets still doesn't.
