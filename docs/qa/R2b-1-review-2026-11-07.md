**B — event page polish (commit 2)**
- The Admin button sits on the title's line at its end (LTR right, RTL left). It no longer takes a row of its own.
  Tested: the title's y position is the same with and without the button.
- **Full Screen** map button at the bottom-left of the map. It's a CSS expand (`position:fixed; inset:0`, z-index above the
  tab bar), because iOS Safari has no element Fullscreen API. `map.invalidateSize()` runs after each change, and
  `fitMap()` stands down while full. **Close Map** (same button) or Escape closes it, as does any redraw (`show()`).
  It's safe-area aware and tested to stay clear of zoom, Map Labels / Street and Find Me, in EN and AR. While a popup is
  open it steps aside like the other overlay buttons (the existing `popopen` rule).
- **Tile seam (iOS Safari): not reproduced.** I ran Playwright WebKit (iPhone 13 profile, DPR 3) against the live
  Esri tiles, at three zoom levels and in full screen. No seam showed, and every tile transform was a whole pixel
  (`translate3d(20px, -36px, 0)`). The vendored Leaflet 1.9.4 already carries the upstream gap fix
  (`.leaflet-container img.leaflet-tile { mix-blend-mode: plus-lighter }`). Playwright's WebKit doesn't use iOS
  Safari's GPU compositor, so a device-only seam can't be ruled out. **No CSS change was made blind.** Next step if
  it recurs: a screenshot from the phone at a known zoom, plus whether it appears while panning or at rest.

## Deviations from the plan (all small; flagged for the reviewers)

1. **Home-pin "adjusted" is limited to `kind = 'homes'` events.** The plan says live events. A one-place event
   doesn't use the home pin, so telling those households "adjusted" would be false. Test O08g.
2. **"Adjusted" isn't cleared by a household's answers update while still in.** Only by its switch / supply /
   supply-clear, a re-join, or vacate, as the plan lists. Test O06d pins this.
3. **Organizer switch / supply buttons show from 2 h before the start until the close** (the household's event-day
   lead-in; undated events never show them). Remove Sign-Up shows whenever the event is live. The server doesn't
   time-gate either, matching `jc_entry_live_set`.
4. **Organizer supply: tapping the pressed level does nothing.** Clear Supply is explicit. The household's tap
   toggles, as the plan says.
5. **`jc_admin_entry_withdraw` keeps `hidden` and `org_adjusted_at`** (only status, spot, `org_withdrawn_at`
   and reports change). My Sign-Up shows only the removal line for a non-`in` entry.
6. Admin RPCs don't call `jc_module_on(…, 'events')`, same as the existing admin entry RPCs
   (`jc_admin_entry_pin_set` / `_moderate` / `_spot_set`). The residents' new RPC does.
