## Pre-review fact check (live, 2026-11-08)

- **Bidi (R4a deferred L1):** the live `jc_clean_line` is `jc_clean_text` (strips U+202A–202E and U+2066–2069) plus its own class (U+200B–200F, U+061C, U+2028/2029, U+FEFF). So it **already strips** every character listed. The R4a finding was a false positive, and **the function is not changed**. s18 BD01/BD02 pin the behaviour. The code reviewer confirmed this independently from the migration files: nothing redefines either helper after S2/S3. Event titles don't use `jc_clean_line`: `jc_clean_text` strips the embeddings, overrides and isolates but keeps the LRM, RLM and ALM marks (R2b-2's choice, left as is).
- **Cancel reason (R4a deferred note):** the live `jc_bookings_cancel_range` already writes `left(reason, 200)`, so there was no check violation. A reason over 185 chars was **cut off silently** instead. The fix caps block reasons at 3–185, so `'Court blocked: ' || reason` is always complete.
